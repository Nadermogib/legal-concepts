# legal-concepts

نظام متكامل لمتابعة حضور وانصراف موظفي المفاهيم القانونية للمحاماة والاستشارات، وإصدار تقارير البصمة المعتمدة (يومية وشهرية)، وتوليد وتصدير ملفات PDF بدقة طباعة عالية ودعم تثبيت التطبيق كـ PWA.

## البنية الأساسية
- `client/`: واجهة المستخدم مبنية بواسطة React 19 + Vite + Tailwind CSS.
- `server/`: خادم Express متصل بواجهة جسر (Jisr API) وقاعدة بيانات MongoDB Atlas.

## التشغيل محلياً
```bash
# تثبيت الاعتماديات
npm run install:all

# تشغيل الخادم والواجهة
npm run dev
```

## البناء للإنتاج
```bash
npm run build
npm start
```
